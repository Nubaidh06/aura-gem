--------------------------------------------------------------------------------
REGISTERING A NEW USER (MongoDB insertOne):
--------------------------------------------------------------------------------
To test creating a brand new customer document in MongoDB:
1. Navigate to: http://localhost:3000/register
2. Fill in the name, email, chosen password (min 6 characters), and address.
3. The server hashes the password with bcrypt and executes an insertOne() 
   command into the "customers" collection.
4. You are immediately logged in to the newly created account.

--------------------------------------------------------------------------------
VIVA TALKING POINT (SECURITY IN NOSQL):
--------------------------------------------------------------------------------
"Passwords must never be stored in plain text. When a customer registers, bcrypt 
generates a unique salt and hashes the password before saving the 'password_hash' 
attribute in the MongoDB document. On login, MongoDB finds the customer document 
by email via findOne(), and bcrypt.compare() validates the password hash."
